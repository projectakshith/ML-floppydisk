# Team Floppy Disk — Unit 1–5 code bundle

This folder contains code listings for all five project units. The Python listings are transcribed from Appendix A of `Team_FloppyDisk_Extended_Final_Report.docx`. The original saved Colab notebooks available in the project workspace are also included for Units 4 and 5.

## Files

- `unit_1_ecommerce_statistical_analysis.py` — descriptive analysis; expects `kaggle_ecomm_shipping.csv` and `augmented_ecomm_delivery.csv` in the working directory.
- `unit_2_telecom_churn_classification.py` — Telco churn classification; downloads the public dataset in the notebook code and needs internet access plus the listed Python packages.
- `unit_3_cmapss_clustering.py` — C-MAPSS sensor-window clustering; expects the NASA C-MAPSS FD001 files (or the alternative input path configured in the code).
- `unit_4_taiwan_covid_hmm.py` — HMM/backward-algorithm code listing.
- `unit_4_taiwan_covid_hmm_colab.ipynb` — saved Unit 4 Colab notebook.
- `unit_5_mpesa_inflow_ensemble_regression.py` — recorded M-PESA inflow regression code listing.
- `unit_5_mpesa_real_data_colab.ipynb` — saved Unit 5 real-data Colab notebook.
